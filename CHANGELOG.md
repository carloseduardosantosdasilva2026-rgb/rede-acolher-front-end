# Alterações

## 1.0.1

- Correção da adaptação ao maior contraste e às cores forçadas do sistema com media queries CSS.

## 1.0.0

- Base funcional importada da Experiência III, com três páginas, navegação dinâmica, busca, cadastro e preferências.
- Ajustes de foco, teclado e descrição do armazenamento de preferências.
- Documentação do fluxo de branches e da revisão de acessibilidade.
- Geração de arquivos de produção com CSS e JavaScript minificados, scripts reunidos e SVGs compactados.

O versionamento semântico usa MAJOR.MINOR.PATCH. Mudanças incompatíveis aumentam MAJOR; funcionalidades compatíveis aumentam MINOR; correções compatíveis aumentam PATCH. 1.0.0 identifica a primeira versão consolidada deste repositório.
